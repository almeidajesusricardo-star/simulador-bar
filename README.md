# BarLab — Simulador Financeiro do Bar

Aplicação estática, gratuita e responsiva para simular os resultados de um bar em eventos.

## Recursos

- Estimativa de público, consumo, faturamento, custos e ponto de equilíbrio.
- Recuperação prioritária dos R$ 700 do investidor.
- Divisão do lucro distribuível: **10% para o investidor e 45% para cada operador**.
- Simulações rápidas e compartilhamento dos parâmetros por URL.
- Tema claro/escuro.

## Publicação na Vercel

1. Acesse https://vercel.com/new
2. Importe `almeidajesusricardo-star/simulador-bar`.
3. Selecione **Framework Preset: Other**.
4. Deixe o diretório raiz `./` e não configure comando de build.
5. Clique em **Deploy**.

## Premissas importantes

O custo médio por bebida representa o custo apenas dos produtos vendidos, pressupondo consignação e devolução dos produtos não vendidos. Não estão incluídos tributos, taxas de cartão, quebras ou custos não informados. A devolução dos R$ 700 é prioritária, porém condicionada à disponibilidade de caixa após os custos. Em caso de resultado negativo, não há lucro a distribuir. Formalize a divisão e o risco de prejuízo com os operadores.
